# Analytical history

This is a consolidated exploratory observational analysis, not a preregistration. Initial analyses examined reported lifetime male–male behavior and sexual identity; the behavior association motivated subsequent robustness, behavior-specific, identity-subgroup, and explanatory analyses. The primary p-value is nominal. The documented family-specific multiplicity adjustments do not correct the entire historical search.

The frequentist analyses preceded a Bayesian reanalysis, whose priors were specified after inspecting the frequentist results. The current manuscript scope returns to conventional frequentist inference. Prior implementations, comparisons, simulations and approved figure versions remain recoverable at Git tag `backup/pre-frequentist-only-20261114` (commit `f054058203e6d926b2017e1c2aee5f74bacecb73`). They are no longer part of the active pipeline. History has not been rewritten.

Timing and binary-confounding scenarios followed the main finding. They are sensitivity constructions, not observed timing groups or identified mechanisms. The historical procedure-count extrapolation does not establish an adult-share upper bound. The separate Maloney implementation is retained as an optional supplement; its inclusion remains pending an editorial decision.

The repository began with consolidated public code rather than importing private exploratory development commits. Neither its initial clean history nor this refactor implies prospective specification. Numerical validation is not independent population replication. The manuscript has not been edited by this refactor.
