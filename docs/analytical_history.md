# Analytical history

The frequentist analyses were conducted before the Bayesian reanalysis. Bayesian questions and priors were documented after inspecting the frequentist findings; this is not a preregistration of unseen data.

The initial Bayesian implementation used the vector of survey-adjusted coefficients and covariance as an approximate Gaussian likelihood, with a t sensitivity and prior sensitivity analyses. A later comparison retained the full logistic likelihood and tested alternative design calibrations. The direct proper-prior implementation now leads the headline comparison because it avoids dependence on an unregularized estimate that can fail in sparse samples. The earlier approximation remains available and has not been erased or relabeled. Method choice is not based on obtaining a larger directional probability.

Timing sensitivities followed the main analyses and remain conditional scenarios. The historical count benchmark is not a complete adult-procedure upper bound. The Maloney supplement remains separate, using326 eligible men as primary and325 as a documented exclusion sensitivity. No cross-study meta-analysis is included in this release.

The public repository contains consolidated code/configuration/documentation and normal release updates, without importing private exploratory development commits or data. Its limited history does not imply prospective specification. The manuscript was not edited for this code reorganization.
